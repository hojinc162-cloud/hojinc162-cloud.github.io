개인정보 처리 안내

오늘의느낌 자동업로드는 운영자 본인의 YouTube 채널을 관리하기 위한 개인용 프로그램입니다.

접근하는 정보와 목적

Google OAuth 승인으로 받은 연결 정보와 YouTube 채널 ID·채널 이름·업로드 목록 및 영상 메타데이터를 사용합니다. 채널 확인, 영상 업로드, 중복 업로드 방지에 필요한 범위로 사용합니다. 시청자의 생년월일이나 개인 사주 정보는 수집하지 않습니다.

저장과 처리

연결 정보에는 접근 토큰·갱신 토큰이 포함됩니다. 운영자의 PC 내 비공개 폴더와 비공개 GitHub 저장소의 암호화된 Actions secret에 보관합니다. GitHub Actions에서 프로그램을 실행하며 Google의 공식 API로 채널 정보를 확인하고 영상을 업로드합니다. 인증정보를 공개 코드나 영상 설명에 넣지 않습니다.

업로드 날짜, 영상 ID, 처리 상태는 중복 방지를 위해 비공개 저장소에 기록합니다. 제작된 영상과 업로드 결과의 GitHub 실행 산출물 보관 기간은 1일로 설정합니다. 게시된 영상은 선택한 공개 상태로 YouTube에 보관됩니다.

정보 공유와 사용 제한

Google 사용자 정보는 이 페이지에서 설명한 채널 관리 기능에만 사용합니다. 판매, 광고 타기팅 또는 AI 모델 학습에 사용하지 않습니다. 프로그램 실행과 게시에 필요한 GitHub 및 Google 서비스를 사용합니다. 영상 공개를 선택하면 영상과 제목·설명은 YouTube 이용자에게 공개됩니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

연결 해제와 보관 종료

운영자는 Google 계정의 서드 파티 연결에서 이 앱의 접근 권한을 해제할 수 있습니다. 사용 종료 시 GitHub Actions secret과 PC의 연결 파일을 삭제하고 예약 실행을 중지합니다. 업로드 기록과 영상의 삭제는 각 저장소와 YouTube Studio에서 별도로 관리합니다.
